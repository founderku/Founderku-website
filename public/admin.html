Masuk admin

Buat nyambungin ke GitHub, isi token akses pribadi (personal access token) yang punya izin baca-tulis ke repo founderku. token ini cuma kesimpen di browser kamu sendiri, ga dikirim ke mana-mana selain GitHub.

Buat token baru di github.com → settings → developer settings → personal access tokens. kasih izin "repo" (contents read & write).
